# A lazy section reads itself again

Owner: refresh one section at a time without reloading the page.

## Plan

- `Again` on kit.Section draws a Read again icon button in the head (aria-label and title "Read <title> again"), a link to the page with fresh=1 without JavaScript.
- On a lazy section kit.js reloads only that section through load(), from Src with fresh=1 added and its query kept; busy while it loads, the section's error box with Retry when it fails. The button stays in the loaded head.
- Goldens, kit.js tests, README.
