# Links carry the page's address when it changes without a reload

Owner bug in the control room: after a toolbar sort (it reloads only its section and changes the address with replaceState), Read again, the product tabs and the GitHub light's back still hold the address of the first load, so the sort resets.

## Plan

- `Carry` on kit.Link, kit.Tab and kit.Button draws `data-ui-carry="<own values>"`; kit.js gives those links the page's new query after a toolbar or the view toggle changes the address, keeping their own values (fresh, tab).
- `Back` on kit.Light draws `data-ui-back="back"` on the lazy box; `Back` on kit.Hidden draws `data-ui-back` on the input; kit.js puts the page's address there.
- The server draws them right for the first load; F5 needs none of it.
- Goldens, Go tests, kit.js tests (`test/`, in `npm test`), README.
