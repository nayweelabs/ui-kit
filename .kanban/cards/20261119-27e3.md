# License and features section

Step S2 of the license epic (epic card KBN-20261106-e99b on the control-room board). The "License and features" section of every app's Settings page, built once in ui-kit and drawn from sample data. What it shows is on control-room card 6104; the look is the design the owner approved on 19 Nov 2026 (artboards "Settings · License and features" and "License states").

No product tag: ui-kit is not in hubman's catalog.

## What it does
- One part, `ui/license` (Go partial, classes, React wrapper `License`), in one module.
- License card: the state (none, trial, trial-ended, licensed, ending, dev), each license file read (for, kind, until, signing key id), this build (release or not), a countdown bar for a trial and a license's last days, the app's own buttons, and, with no license or an ended trial, a button that says how to get a trial key (the app passes where to ask; no app starts a trial).
- Features table: each feature with what it covers, tier, state (On, Off, Locked), why, and what unlocks it. An enterprise feature that is on but misses a value says so.
- It draws what it is given and decides nothing (G-STACK-7): the order, the countdown and every value come from the app.
