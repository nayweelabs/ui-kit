# A form asks in the kit's dialog before it changes anything

Plan (design plan-confirm-changes, block KIT on the constitution board):

- A form, or its submit button, marked `data-ui-confirm="<question>"` opens the kit's dialog before it submits: the question, Cancel (first focus) and a button repeating the verb (`data-ui-confirm-label`, default the button's text). Escape or Cancel sends nothing; the confirm button sends the form with the button's name and value.
- `data-ui-undoable` adds "Don't ask again"; checked, the form sends `confirm=skip` too. The server remembers and draws the form without the mark next time.
- Go: `Confirm` (the question) and `Undoable` on `kit.Button`. React: `<ConfirmForm>`, and `Dialog` takes children like the Go Body.
- Without JavaScript the form sends at once.
- Tests: kit.js in the stand-in DOM, a golden case, React wrapper. Docs in the README.
