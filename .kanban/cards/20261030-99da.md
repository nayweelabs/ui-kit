# Preview banner: a build that is not a release says so at the top

Owner (2026-10-30): "sometimes you show me a preview of the product and I need to check the footer to see if it is a branch or main. If it is a preview, at the top, clearly say this is a preview, so I can tell. This applies to each UI product."

## Plan

- `kit.Build` (Version, Branch, Commit, Dirty, Released): what the running build was made from. The app decides Released from its own build info; the kit only draws it.
- `ui/preview-banner` draws, above the top bar, a full-width band of amber and black stripes no other part uses: "PREVIEW · branch feat/x · 758ac48 · not a release · uncommitted changes". A released build draws nothing. Not dismissible, sticky on top; the bar and rail move down under it.
- `kit.Page.Build *Build` puts it in `ui/shell`; nil draws nothing, so apps that do not send it are unchanged.
- React `PreviewBanner` with the same markup; `Shell` takes `build`.
- Tokens `preview`, `on-preview` (same in both themes, contrast tested) and `preview-h`.
- Golden cases branch, dirty, released; a shell test; a wrapper test; README; design block CMP-BANNER.
