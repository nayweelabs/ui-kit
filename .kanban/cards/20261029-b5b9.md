# A link can reload only its lazy section

For the control room's road graph: a group node expands in place. A link with `data-ui-section-link` inside a lazy section makes its href the address and reloads only that section, like a toolbar's GET form; without JavaScript it is a plain link.

## Plan

- kit.js: click on `.ui-lazy a[data-ui-section-link]` (not with a modifier key) → replaceState, carry, load the section with the new query; works for `<a>` in inline SVG.
- A kit.js test and README.
