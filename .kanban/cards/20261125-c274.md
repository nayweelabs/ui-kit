# Run ui-kit's CI on GitHub-hosted runners

ui-kit is to be made public. A public repo must never run on the org's own runners: a fork's pull request would run on the owner's machine. Move every workflow job to GitHub's machines, the same way mankit and contracts did.

- rule-dates.yml: the shared workflow already picks GitHub's machines for a public repo; nothing to pass.
