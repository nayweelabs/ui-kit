# A section link dims its section while it reloads

A View or Show chip, or any section link, reloads only its section, but the old section stayed as it was until the new HTML replaced it: the page changed all of a sudden, with no sign it was working. reloadAt now marks the section data-ui-reloading, the same dim and bar Read again shows.

Found on control-room's Epics page; control-room carries the same CSS until it takes this release.
